# 言葉の一覧

このリポジトリのスクリプト・文書・画面の出力で使う言葉。構成表の項目の書き方は [storyboard.md](storyboard.md)、機能ごとの一覧は [features.md](features.md)。

## 作るもの

| 言葉 | 意味 | 名前 |
|---|---|---|
| 構成表 | 録画のどこを使い、何を重ねるかを書いた JSON | `examples/*-storyboard.json` |
| 行 | 構成表の `rows` の 1 つ。書き出しの 1 区切り (クリップ 1 つ) | `rows` |
| 素材 | 構成表が使う録画のファイル | `source` |
| 組む | 構成表から Resolve のタイムラインを作ること | `sb2resolve.py` |
| 完成版 | Resolve で組んで書き出した動画 | `sb2resolve.py --render` |
| 仮組み | NG の行があっても、完成版とは別のファイルに書き出した確認用の動画 | `sb2resolve.py --render-anyway` |
| 部分の書き出し | 指定した行だけの仮組み | `sb2resolve.py --rows` |
| 簡易版 | Resolve を使わず FFmpeg で描いた動画。完成版に近いが同じではない | `sb2ffmpeg.py` |
| 組み立て内容 | 簡易版を描く元になる、タイムラインのクリップと Fusion の部品の並びの JSON | `*.build.json` |
| 記録 | スクリプトが出力先に書く結果の JSON | `sb2resolve\<構成表の名前>.json` など |
| 照らし合わせ | 構成表・タイムライン・書き出した動画を比べ、項目ごとに pass / fail / unknown を付けること | `check_final.py` |

## 画面に重ねるもの

| 言葉 | 意味 | 名前 |
|---|---|---|
| テロップ | 画面の下 (位置は変えられる) に出す文 | `caption` |
| テロップの背景 | テロップの後ろの半透明の板。帯とも書く | `caption.bar_rgba` |
| 結びのテロップ | 画面の中央に大きく出すテロップ | `caption_style: "closing"` |
| 肩テロップ | 画面の右上に、行の頭から決まった秒だけ出す短い文と板 | `badge` |
| マスク | 範囲をモザイク・ぼかし・黒塗りで隠すもの | `masks` |
| 動くマスク | 時刻ごとの位置 (`keys`) で動くマスク | `masks[].keys` |
| ズーム | ズーム範囲が画面いっぱいになるまで寄せること。`direction: "out"` なら引く | `zoom` |
| 周りを暗くする | 範囲の外を暗くして、範囲に目を向けさせること | `focus` |
| 枠線 | 周りを暗くする範囲の縁の線 | `focus.border` |
| 暗い背景・明るい背景 | 枠線の色を `auto` にしたとき、範囲の縁の明るさで分ける 2 つの場合 (暗い背景は黄、明るい背景は赤) | `focus_border.auto` |
| 止める | 行の後ろで 1 枚の画を映し続けること。その区間を止めた区間と書く | `hold` |
| 拡大の重ね表示 | 素材の一部を切り抜いて拡大し、画面の上に重ねるもの | `callout` |
| 切り抜き | 拡大の重ね表示で切り抜く素材の範囲 | `callout.src` |
| 置き場所 | 拡大の重ね表示を置く場所。省くと自動の置き場所 | `callout.dst` |
| 指すマーク | 画面の 1 点を 👆 などの字で指すもの | `point` |
| 配置 | 画面を縮めて寄せ、余白にテロップを出す形 | `layout` |
| 余白 | 配置で画面の外に空いた所 | `layout` |
| 解説の欄 | 配置の余白に並べる、見出しと中身の欄 | `side` |
| セーフエリア | 書き出しの中で、大事なものを収める中央の範囲 (既定は書き出しの全体) | `safe_area` |

## 時間と座標

| 言葉 | 意味 |
|---|---|
| 素材の時刻 | 録画の中の時刻。行の `start`・`end` |
| 行の頭 | 書き出しでその行が始まる所。`zoom.seconds`・`focus.start` などはここからの書き出しの秒 |
| 倍速・等倍・遅くする | 使う範囲の長さ ÷ 行の長さが 1 より大きい・1・1 より小さい |
| 素材の画素 | 録画のファイルの画素の座標 (左上が 0,0) |
| 書き出しの画素 | 書き出す画面 (`timeline` の大きさ) の画素の座標 (左上が 0,0) |

## 録画と確認のツール

| 言葉 | 意味 | 名前 |
|---|---|---|
| ピン | 録画の時刻の目印 | `marker.html`・`pins.py` |
| 領域 | 録画の上で囲んだ四角か楕円 | `marker.html` (`<録画の名前>.marks.json`) |
| 出来事の候補 | 録画から見つけた、画面の切り替わり・長い静止・エラーの語の時刻 | `scene_events.py` |
| 位置の JSON | 録画の中で見つけた文字や部品の、隠す位置 | `track.py` (`*.track.json`) |
| 見る範囲 | 書き出した動画の中で、変化を並べて確認する範囲 | `area_sheet.py --area` |
| 作業フォルダー | 作業の途中のファイルを置くフォルダー | `paths.work_dir` (既定 `%USERPROFILE%/Videos/storyboard-work`) |
| 出力先 | 記録と書き出しを置くフォルダー | `paths.out_dir` (既定 作業フォルダーの `out`) |
| 仮組みの書き出し先 | 仮組みと部分の書き出しの既定のフォルダー | `paths.preview_dir` (既定 `%USERPROFILE%/Videos/storyboard-preview`) |
| Resolve のロック | Resolve を使う処理を 1 つずつにするための、作業フォルダーの `resolve.lock` | `resolve_lock.py` |

## 指示で使われる別の言い方

指示や相談で使われることがある言い方と、このリポジトリの言葉の対応。`python scripts/features.py 語` で探すとき、左の言い方は右の言葉に読み替えて探す (括弧の中は読まない)。

| 指示での言い方 | このリポジトリの言葉 |
|---|---|
| 字幕、スーパー | テロップ |
| 締めのテロップ、まとめのテロップ | 結びのテロップ |
| 札 | 肩テロップ |
| 帯 | テロップの背景 (テロップの話で)、見る範囲 (`area_sheet.py` の話で、範囲の名前を付けて指定するもの) |
| モザイク、ぼかし、伏せ字 | マスク |
| 寄り、寄せる | ズーム |
| スポットライト、ハイライト | 周りを暗くする |
| 赤枠、囲み | 枠線 |
| 黒バック | 暗い背景、明るい背景 (枠線の色の話で) |
| 白バック | 明るい背景 |
| ルーペ、拡大鏡 | 拡大の重ね表示 |
| 矢印、指差し | 指すマーク |
| L 字、額縁 | 配置 |
| 解説パネル、サイドパネル | 解説の欄 |
| 早送り、早回し | 倍速 |
| スロー | 遅くする |
| 静止、フリーズ | 止める |
| プレビュー、確認用の書き出し | 仮組み |
| 試作版 | 簡易版 |
| 突き合わせ、検証 | 照らし合わせ |
| 目印 | ピン |
