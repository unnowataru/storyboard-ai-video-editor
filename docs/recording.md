# 録画と録画まわりのツール

画面録画を撮るときの注意と、録画の後に場面を探すためのツール (`wallclock_to_tc.py`・`marker.html`・`pins.py`・`scene_events.py`・`contact_sheet.py`) の使い方。構成表の書き方は [storyboard.md](storyboard.md)、画面の文字を隠す位置の求め方は [track.md](track.md)。

## 録画を撮るときの注意

### 解像度とフレームレート

- 構成表のフレームレートの既定は 30 fps、タイムラインの既定は 1920x1080 (config の `storyboard.fps` と `storyboard.timeline`)。録画も同じフレームレートで撮る。素材と構成表のフレームレートが違うと、focus の枠線の色 (`auto`) で見るフレームは近似になり、警告が出る。速さを変えた行の Fusion の時刻の換算も、フレームレートが違う素材では確認していない
- マスク・ズーム範囲・focus などの座標は素材の画素で書き、組むときに素材の解像度でタイムラインの画素に換算する。見本の構成表 (`examples/`) は 4K (3840x2160、30 fps) の素材に合わせてある
- 素材の縦横の比がタイムラインと違うときは、素材を拡大も縮小もせずに真ん中に置き、余りを黒で埋める

### 音

- 簡易版 (`sb2ffmpeg.py`) は音を入れない
- 完成版 (`sb2resolve.py`) は素材を音ごと置く。行の速さを変えると、つながった音の速さも変わる

### 機密の隠し方

- 元の録画は加工しない。隠すのは Resolve の中 (Fusion のマスク) で、マスクの位置は構成表に書く。IP アドレス・ホスト名・指定の文字列・画面の部品の位置は `track.py` で求められる ([track.md](track.md))
- `track.py` と `scene_events.py --ocr` の文字認識は Windows 標準の文字認識を手元で使い、画面の内容を外部へ送らない。結果の JSON には読んだ文字そのものを書かない
- 作業フォルダーの既定は `%USERPROFILE%/Videos/storyboard-work`。機密を含む画面のフレームを書き出すことがあるので、クラウドで同期しているフォルダーを作業フォルダーにしない
- 書き出した動画のマスクの漏れは `area_sheet.py` で、見る範囲が変わったフレームを全部並べて目で確認する (`python scripts/area_sheet.py --help`)

## 時刻の記録と直し方

録画を一時停止しながら撮ると、作業のメモやチャットの記録に残った壁の時計の時刻 (例 10:09:30) と、録画の中の時刻がずれる。録画ツールが操作ごとに時刻の記録 (`rec-timeline.log`) を書いておけば、`wallclock_to_tc.py` で壁の時計の時刻を録画の中の時刻に換算できる。

### 時刻の記録の形式

UTF-8 のテキストで、1 行に 1 つの操作を、タブ区切りの 4 列で書く。改行は LF でも CRLF でもよい。

| 列 | 内容 | 例 |
|---|---|---|
| 1 | 壁の時計の時刻 `YYYY-MM-DD HH:MM:SS` | `2026-10-01 10:00:00` |
| 2 | その時点の録画の時刻 `hh:mm:ss.sss`。空でもよい | `00:05:00.000` |
| 3 | 操作の種類。空白の後ろに続く文字 (保存したファイルのパスなど) は読まない | `start`、`stop rec/a.mp4` |
| 4 | メモ。`wallclock_to_tc.py` は読まない | `場面 1` |

操作の種類と、`wallclock_to_tc.py` の読み方:

| 種類 | 意味 | 読み方 |
|---|---|---|
| `start` | 録画を始めた | 録画が進む区間の始まり。録画の時刻は 2 列目 (空なら 0 秒) |
| `resume` | 一時停止から再開した | `start` と同じ |
| `status` | 録画が進んでいることを確認した (録画の途中から記録を始めたときなど) | 区間が開いていないときだけ、区間の始まりとして読む。区間の途中の `status` は読まない |
| `pause` | 一時停止した | 区間の終わり |
| `stop` | 録画を止めた | 区間の終わり |
| `pin` | 録画中にピンを打った | 読まない |

- 3 列に満たない行と、3 列目が空の行は飛ばす。知らない種類の行も区間に影響しない
- `stop` の無い記録は、最後の `start`・`resume` から先も録画が続いているとみなす
- 時刻は記録の最後の操作の行の日付で読む。日付をまたぐ記録は扱わない

例 (5 分録って 5 分止め、10 分録る。列の間はタブ):

```text
2026-10-01 10:00:00	00:00:00.000	start	
2026-10-01 10:05:00	00:05:00.000	pause	
2026-10-01 10:10:00	00:05:00.000	resume	
2026-10-01 10:20:00		stop rec/a.mp4	
```

### wallclock_to_tc.py の使い方

```text
python scripts/wallclock_to_tc.py rec-timeline.log 10:01:00 10:07:00 10:12:30
```

時刻は `HH:MM:SS` でいくつでも渡せる。上の記録なら、次のように録画の中の `m:ss.s` を出す。一時停止中と録画の外の時刻は「録画に入っていない」と出る。

```text
10:01:00 → 1:00.0
10:07:00 → 録画に入っていない (一時停止中か録画の外)
10:12:30 → 7:30.0
```

換算した時刻は実際より 1〜2 秒早く出る。前後のフレームを `contact_sheet.py` で並べて場面を決める。操作の行が 1 つも無い記録は「記録に操作の行が無い」で終わる。

## marker.html (再生しながらピンと領域を付ける)

`scripts/marker.html` をブラウザーで開き、録画のファイルを選ぶ。再生しながら場面の時刻にピンを打ち、隠したい所や照合の見本にする所を四角か丸で囲む。

| 操作 | キーとボタン |
|---|---|
| 再生・一時停止 | Space か「再生 / 一時停止」 |
| ピンを打つ | P か「ピン」 (URL の `?pinkey=` で足したキーも) |
| 囲む形を選ぶ | R (四角) か E (丸) |
| 囲む | 動画の上をドラッグ |
| 付けたものへ飛ぶ・消す | 一覧の「移動」「消す」 |
| 保存する | 「保存」 |

「保存」で `<録画の名前>.marks.json` がダウンロードされる。形は次のとおり。領域の座標は元の動画の画素、時刻は秒。

```json
{
 "video": "a.mp4", "width": 3840, "height": 2160,
 "pins": [{"t": 12.5, "name": "ピン1"}],
 "regions": [{"shape": "rect", "t": 3.0, "x": 100, "y": 200, "w": 300, "h": 40}]
}
```

- `shape` は `rect` (四角) か `ellipse` (丸)
- 領域は `track.py --template 録画.marks.json:0` の見本に使える。`:0` は `regions` の中の番号 (0 始まり)
- 別の動画を選ぶと、前の動画のピンと領域は消える
- URL に `?src=動画の URL` を付けると、その動画を開く。結果は `window.marks` にも置くので、ブラウザーの自動操作で読める
- URL に `?pinkey=キー` を付けると、P のほかにピンを打つキーを足せる。例: `?pinkey=ctrl+k`。修飾キーは `ctrl`・`alt`・`shift`・`meta` を `+` でつなぎ、最後にキーの名前 (`KeyboardEvent.key` の名前。`F9`・`Enter`・`a` など) を書く。大文字小文字は区別しない。書いた修飾キーをちょうど押したときだけ合う。キーに `+` を使うときは `%2B` と書く

## pins.py (一覧)

録画ツールが録画ファイルに書いたピン (チャプター。OBS のチャプターなど) と、`marks.json` のピンと領域を、時刻の順に一覧にする。

```text
python scripts/pins.py 録画.mp4 [marks.json] [--json]
```

- `marks.json` を省くと、録画と同じフォルダー、作業フォルダーの `<録画の名前>\`、ダウンロードのフォルダー (config の `paths.downloads_dir`、環境変数 `RESOLVE_DOWNLOADS`) の順に `<録画の名前>.marks.json` を探す
- 種類は `ピン (OBS)` (録画ファイルのチャプター)・`ピン`・`四角`・`丸`。同じ時刻なら、この順に並ぶ
- 録画ファイルのチャプターは全部出す。録画ツールが自動で付けたチャプター (録画の始めや終わりの印など) も出るので、一覧を見て除く
- `--json` は表の代わりに JSON を出す。領域の行には `marks.json` の中の番号 (`index`) が付く

## 録画の後に出来事の候補を出す

`scene_events.py` は録画ファイルから出来事の候補を時刻つきで出す。ピンは打たず、元の録画は書き換えない。候補は人が見て選ぶ。

```text
python scripts/scene_events.py 録画.mp4 [--ocr] [--json] [--out 候補.json]
```

| 種類 | 内容 |
|---|---|
| `change` | 画面の大きな切り替わり。画面が落ち着いたところで 1 件 (スクロールの途中では出さない) |
| `still-start` | 長い静止 (`still_sec` 秒以上、画面がほぼ動かない区間) の始まり。待ちとは限らない |
| `still-end` | その静止の終わり |
| `error-word` | エラーの語 (`error_words`) が、前に読んだときには無く、新しく映った (`--ocr` のときだけ) |

- 結果は `--out` に保存する。既定は `作業フォルダー\<録画の名前>\<録画の名前>.events.json`。形は `{"video", "duration", "ocr", "events": [{"t", "kind", "note"}]}`
- `--ocr` は、何かが現れて落ち着いたフレームだけを文字認識にかける。時間がかかる。説明の文が映る録画 (AI のチャットの画面など) では、説明の中の「エラー」「失敗」も拾う。認識に使うフレームは作業フォルダーに置き、終わったら消す
- 読む間隔・判定のしきい値・語は config の `scene_events` (`step_sec`・`width`・`level`・`change_ratio`・`settle_ratio`・`still_ratio`・`still_sec`・`ocr_ratio`・`ocr_scale`・`error_words`)

## 場面探しと確認 (contact_sheet.py)

`contact_sheet.py` は動画のフレームを時刻付きで 1 枚の画像に並べる。録画の場面探しと、書き出した後の確認に使う。

```text
python scripts/contact_sheet.py 録画.mp4 [出力先]
python scripts/contact_sheet.py 録画.mp4 [出力先] --step 2 --from 14:58 --to 15:30 --cols 4 --rows 4
python scripts/contact_sheet.py 動画.mp4 [出力先] --frames 149,150,209,210
```

- 既定は 10 秒ごとに 1 フレーム、5x4 で 1 枚 (config の `contact_sheet`)。出力先の既定は `作業フォルダー\<動画の名前>\sheets`
- 画像の左上に元の動画の中の時刻 (h:mm:ss) が入る。`--from` を付けても通しの時刻で出る
- `--frames` は番号 (0 始まり、カンマ区切り) を指定したフレームを、番号と時刻付きで並べる

## つまずいた所

- FFmpeg と ffprobe は低い優先度 (BELOW_NORMAL) で動かす。録画や別の作業と同じ PC で流しても重くしないため
- 録画ファイルにチャプター (録画ツールのピン) があると、Resolve はそれをクリップのマーカーとして読み込む。そのクリップには `sb2resolve.py` が行の目印のマーカーを付けられない (警告が出る)。`read_markers.py` はそのとき `sb2resolve.py` の記録で行を決める ([scripting-api.md](scripting-api.md#マーカー))
- `marker.html` は、ファイルを選んだ後に選択欄からフォーカスを外す。フォーカスが残ると、Space で再生ではなくファイルの選択画面が開くため
